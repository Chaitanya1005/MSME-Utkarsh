To exercise this manually against a running backend:

```bash
# Log in as bm.a101
TOKEN=$(curl -s -X POST http://localhost:4000/api/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"username":"bm.a101","password":"ChangeMe123!"}' | jq -r .data.token)

# Allowed: their own branch
curl -s http://localhost:4000/api/org/branches/<branchA101Id> \
  -H "Authorization: Bearer $TOKEN"

# Denied: a different branch — expect 403 AUTHORIZATION_ERROR
curl -s http://localhost:4000/api/org/branches/<branchB101Id> \
  -H "Authorization: Bearer $TOKEN"
```

(Branch/region IDs are generated `cuid()`s — fetch them from
`GET /api/org/scope` after logging in as the relevant RM, or from Prisma
Studio / `psql`.)
